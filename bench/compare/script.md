# Side-by-side script

Read each numbered prompt aloud, naturally (ums and restarts are fine), once
into Handy Flow and once into Wispr Flow. Dictate the Wispr Flow results into
`wispr.txt`, in order, leaving the `## N` headings in place. Handy Flow's
results are read from its history, so those can go anywhere.

1. So a few things about the trip. One, I still need to book the hotel. Two, we should figure out who is driving. And three, somebody has to tell Sam we're coming.
2. Can you grab milk, eggs, a loaf of bread, and some coffee on your way back?
3. To set up the project, first clone the repo, then run the install script, then copy the example config and fill in your API key, and finally start the dev server.
4. I think we have two real options here. We could ship it this week with the known bug, or we could wait until Monday and fix it properly. I lean toward waiting.
5. Let's meet on Thursday, actually no, Friday at two works better for me.
6. Hey Jordan, thanks for the notes yesterday, they were really helpful. On a different topic, are we still on for lunch next week? Let me know what day works.
7. What's the fastest way to get from the airport to downtown, and roughly how much does it cost?
8. Write a short email to the team saying the launch moved to the twelfth.
9. Honestly I don't love the new design. It looks nice but it's slower to use, and every time I open it I have to hunt for the search box.
10. The main reasons I'm against it are that it costs more, it takes longer to set up, and nobody on the team has used it before.
11. Remind me to call the dentist tomorrow morning.
12. I I think the the problem is that it, um, restores the clipboard too early, you know, before the app has actually read it.
